## 一、当前首页问题分析

### 1.1 当前结构梳理

| 序号 | 区块 | 高度 | 问题 |
|:---:|------|------|------|
| 1 | 渐变背景 | 500rpx(fixed) | 占据视觉但无实际功能 |
| 2 | 搜索框 | 70rpx | 白色搜索框在深色背景上割裂 |
| 3 | Banner轮播 | 300rpx | 标准尺寸，无明显问题 |
| 4 | 分类横滑 | 190rpx(sticky) | 图标仅90rpx，文字24rpx，辨识度低 |

## 二、三套重构方案

### 方案A：「层次卡片流」— 现代电商风

**设计理念**：清晰的视觉层次，统一的卡片化设计，改善间距和呼吸感

**核心改动**：

| 改动项 | 原方案 | 新方案 | 改进点 |
|------|------|------|------|
| 头部 | 仅渐变背景+搜索 | 渐变背景+定位+搜索+扫码 | 功能更完整 |
| 通知 | 无 | 新增公告跑马灯栏 | 运营信息触达 |
| 分类 | 横滑(90rpx图标) | 4×2网格(44px图标) | 辨识度+60% |
| 活动区 | 50%宽swiper | 全宽卡片轮播 | 视觉冲击力 |
| 促销区 | 50%宽小图(120rpx) | 横滑卡片(180rpx大图) | 细节更清晰 |
| 主卖区 | 固定640rpx swiper | 自适应双列网格 | 灵活性 |
| 区块标题 | 无标识 | 蓝色竖线+标题 | 层次分明 |
| 间距 | 20/30rpx混用 | 统一12px边距 | 一致性 |

**布局结构**：
```
[深蓝头部] 定位栏 + 搜索 + 扫码
[公告栏]   跑马灯通知
[Banner]  全宽圆角轮播
[金刚区]   4×2 网格图标
[活动区]   全宽卡片 + 活动标签
[促销区]   横滑大图卡片
[主卖区]   双列网格 + 抢购按钮
[商品列表] 瀑布流(复用)
```

**配色方案**：
- 主色：#003B73（深蓝）
- 背景：#f5f5f5
- 卡片：#ffffff
- 公告：#fff3e0（暖橙底）
- 价格：#003B73（主色）

### 方案B：「沉浸式品质」— 高端品质风

**设计理念**：沉浸式视觉体验，品质感，强视觉冲击力

**核心改动**：

| 改动项 | 原方案 | 新方案 | 改进点 |
|------|------|------|------|
| 头部 | 渐变+搜索 | 沉浸式头部+问候+搜索浮层 | 品质感 |
| 快捷入口 | 无 | 浮动圆形图标(5个) | 功能直达 |
| 秒杀 | 无 | 倒计时+横滑商品 | 紧迫感转化 |
| 活动区 | 50%宽 | 全宽卡片 | 视觉完整 |
| 排行榜 | 无 | 编号式热销TOP3 | 社会证明 |
| 商品卡 | 简单双列 | 大图+标签+圆形加购 | 信息丰富 |
| 头部高度 | 500rpx(背景) | 200rpx(内容) | 品牌氛围 |

**布局结构**：
```
[沉浸头部] 问候 + 搜索浮层 + Hero Banner
[浮动卡片] 5个圆形快捷入口
[限时秒杀] 倒计时 + 横滑商品(4个)
[活动专区] 全宽活动卡片
[热销榜单] TOP3 编号排行
[为你推荐] 双列大图卡片 + 标签
```

**配色方案**：
- 主色：#003B73（深蓝）
- 秒杀：#e74c3c（红色）
- 榜单：#e74c3c/#ff9500/#f59e0b（金银铜）
- 卡片：#ffffff（白底浮起）

---

### 方案C：「效率极简」— 极简实用风

**设计理念**：信息密度优先，快速浏览，最少装饰

**核心改动**：

| 改动项 | 原方案 | 新方案 | 改进点 |
|------|------|------|------|
| 搜索 | 70rpx | 32px紧凑 | 节省空间 |
| 分类 | 图标横滑(190rpx) | 文字Tab(40px) | 空间-60% |
| 内容 | 无筛选 | Tab切换(5类) | 精准定位 |
| 活动+促销 | 50/50分栏 | 双卡片横排 | 信息密度 |
| 商品 | 仅瀑布流 | 列表+网格双模式 | 浏览灵活 |
| 每屏商品 | 2个 | 4-5个 | 密度翻倍 |
| 装饰 | 渐变背景 | 去除 | 专注内容 |

**布局结构**：
```
[紧凑头部] 搜索 + 扫码
[Banner]   小尺寸圆角
[分类Tab]  文字横滑(推荐/水果/蔬菜...)
[筛选Tab]  全部/促销/新品/热销/限时
[活动条]   双卡片横排(秒杀+满减)
[商品列表] 列表视图(左图右文) + 模式切换
```

**配色方案**：
- 主色：#003B73（深蓝）
- 背景：#f5f5f5
- 秒杀：渐变橙红
- 满减：渐变蓝
- 极简：仅主色+语义色

## 四、推荐建议

### 综合推荐：方案A（层次卡片流）

**理由**：
1. **改造成本可控**：在现有架构上调整布局和样式，不需要大改JS逻辑
2. **兼容性最好**：保持原有的数据请求和组件结构
3. **效果显著**：解决了P1-P7全部核心问题
4. **可扩展性强**：后续可逐步融入方案B的秒杀/榜单模块

### 分阶段实施建议

| 阶段 | 内容 | 预计改动 |
|:---:|------|------|
| 第一阶段 | 方案A基础布局（头部+分类+间距统一） | index.wxml + index.wxss |
| 第二阶段 | 活动区+促销区重构 | index.wxml + index.wxss |
| 第三阶段 | 融入方案B秒杀模块（可选） | 新增组件 |
| 第四阶段 | 融入方案B榜单模块（可选） | 新增组件 |

## 五、技术实现注意事项

1. **保持原有数据接口**：所有API请求不变，仅调整前端展示
2. **分类网格化**：将`cateScroll`从`scroll-view`改为`grid`布局
3. **间距系统化**：统一使用 `--spacing-xs: 8rpx; --spacing-sm: 12rpx; --spacing-md: 20rpx; --spacing-lg: 30rpx;`
4. **sticky保持**：分类区域sticky定位保留，但样式优化
5. **商品列表组件**：`goodslist`组件可复用，仅调整卡片样式
6. **性能考虑**：横滑区域使用`scroll-view` + `enable-flex`，避免重排
